# ✍️ Contrato Vivo

Esta carpeta resguarda los contratos simbólicos nacidos en el marco del proyecto Tékhne Sílaba.

Aquí no se firman obligaciones jurídicas, sino compromisos vivenciales, espirituales, éticos o simbólicos que expresan un lazo profundo con lo que estamos co-creando.

Cada contrato puede estar acompañado por:

- Un texto en lenguaje claro y sentido
- Un gesto o acto simbólico
- Una dedicatoria o invocación
- Un archivo PDF que documente ese momento

El propósito no es institucionalizar lo invisible, sino ofrecerle una forma cuidada donde pueda permanecer y transformarse.

### Primer Contrato Vivo

> El gesto del abrazo a uno mismo  
> Un acto de reconocimiento a la conciencia que nos reunió para este proyecto.  
> Escrito y ofrecido por Ignacio (Nacho) en julio de 2025.
